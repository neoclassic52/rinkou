# RINKOU-燐光-

**音で、覚醒する。** — 音楽とともに進化する縦スクロール・スペースシューティング。

パワーアップアイテムを取るたびに機体が 1.0 → 3.6 の９段階で進化し、2.0・3.0 に到達した瞬間に音楽が切り替わります。
放射弾の **SPREAD** とレーザーの **LASER**、２つのルートにそれぞれ３曲、合計６曲のオリジナル楽曲を収録しています。

## 遊び方

`index.html` をWebサーバー経由で開いてください（GitHub Pages で公開した場合はそのURLから遊べます）。
音楽・効果音を読み込むため、ファイルをダブルクリックで直接開くと音が鳴りません。ローカルで遊ぶ場合は、例えば次のように起動します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開き、「出撃する」を押すとスタートします。

## 操作

| 操作 | 内容 |
|---|---|
| マウス移動 / 指でドラッグ | 機体の移動 |
| 自動 | ショット（常時発射） |
| 右クリック / 短いタップ / Space / B | ボム |
| 矢印キー / WASD | キーボードで移動 |
| P / Esc | 一時停止（音量・ボイス音量の調整） |

## 確認用テストモード

URLの最後に次の文字を付けて開くと、途中から始められます。

| URL | 内容 |
|---|---|
| `?test=boss` | ラスボス戦の直前から（最終形態3.6・ボム5個） |
| `?test=finish` | ラスボスの体力が残りわずかの状態から（撃破後の余韻とエンディングを確認） |
| `?test=ending` | エンディング映像から直接 |

例：https://neoclassic52.github.io/rinkou/?test=finish

## ゲームの特徴

- **９段階の進化**：SPREAD は子機編隊を経て「翠光の火の鳥」へ、LASER は「蒼光の女神」へ変身します。
- **５つの宙域**：燐光の星雲 → 氷晶の裂け目 → 極光の海 → 光の回廊 → 事象の地平（ブラックホール）。光の回廊では画面が奥へ傾き、奥へ突き進む視点になります。
- **個性ある敵**：蛍・燕・甲虫・水母・風車・監視眼・鳳仙花・光竜・氷華の９種類。
- **ボス**：中ボス「月影の番人 ツクヨミ」、ラスボス「黒曜星核」（砲台の個別破壊・３段階の形態変化）。
- **サウンドルーム**：タイトル画面の「♪ サウンドルーム」から、ゲームの６曲とエンディング曲を聴けます。
  - HOTARU 1.0 — FIRST LIGHT／HOTARU 2.0 — SWARM／HOTARU 3.0 — EMERALD PHOENIX
  - KAGERO 1.0 — BLUE MIRAGE／KAGERO 2.0 — PARALLEL RAYS／KAGERO 3.0 — AZURE GODDESS
  - RINKOU — AFTERGLOW（エンディング）
- **エンディング**：ラスボスを倒すと、真の敵との最後の戦いを描く約1分15秒のエンディング（オリジナル曲）が流れます。クリアした機体（火の鳥／女神）が主役です。クリック・タップでスキップできます。
- **ボイスと効果音**：パワーアップや警告をアナウンスする英語ボイスと、オリジナル効果音。2.0・3.0 への大きな進化では、スロー演出と衝撃波で画面上の敵を一掃します。

## ファイル構成

|---|---|
| `index.html` / `style.css` | 画面とデザイン |
| `game.js` | ゲーム本体（進行・当たり判定・描画） |
| `forms.js` | 自機の９段階の姿と武器 |
| `enemies.js` | 敵・中ボス・ボス |
| `stage.js` | ５つの宙域の背景 |
| `audio.js` | 音楽・効果音・ボイスの再生 |
| `ending.js` | エンディング映像 |
